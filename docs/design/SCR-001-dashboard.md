## 1. 画面概要

### 1.1 目的
発送業務の全体状況を一目で把握し、優先対応が必要な発送を即座に確認できる画面。

### 1.2 対象ユーザー
- 倉庫担当者（Ops）
- カスタマーサポート担当者

### 1.3 アクセス経路
- サイドバーメニュー「Dashboard」をクリック
- ログイン後の初期表示画面

## 3. 画面構成要素

### 3.1 ヘッダー
| 要素 | 説明 |
|------|------|
| ハンバーガーメニュー | サイドバーの開閉 |
| アプリケーション名 | "Shipping Service Admin" |
| ユーザープロフィール | ログイン中のユーザー名表示 |
| ログアウトボタン | ログアウト処理 |

### 3.2 サマリーカード（4枚）

#### カード1: 未着手
- **タイトル:** 未着手
- **値:** CREATED ステータスの件数
- **ステータス:** CREATED
- **色:** デフォルト（グレー系）
- **説明:** 注文確定後、まだ出荷指示が出ていない発送
- **重要度:** 低

#### カード2: 出荷作業待ち
- **タイトル:** 出荷作業待ち
- **値:** READY ステータスの件数
- **ステータス:** READY
- **色:** プライマリ（青系）/ 注意喚起色
- **説明:** 出荷指示済み、倉庫作業が必要
- **重要度:** **高（最重要）**

#### カード3: 本日出荷
- **タイトル:** 本日出荷
- **値:** 当日 SHIPPED になった件数
- **ステータス:** SHIPPED (Today)
- **色:** 成功色（緑系）
- **説明:** 本日配送業者へ引き渡し完了した発送
- **重要度:** 中

#### カード4: 返送/トラブル
- **タイトル:** 返送/トラブル
- **値:** RETURNED ステータスの件数
- **ステータス:** RETURNED
- **色:** 警告/エラー色（赤系）
- **説明:** 受取拒否、宛所不明等で返送された発送
- **重要度:** 中

### 3.3 優先対応リスト

| 列名 | 説明 | 表示形式 |
|------|------|----------|
| 注文ID | Order ID | リンク（クリックで詳細画面へ） |
| ステータス | 現在のステータス | Badge（色分け） |
| 配送業者 | Carrier | テキスト（未設定時は "-"） |
| 更新日時 | 最終更新日時 | 相対時間（"2時間前"） |
| アクション | 詳細表示 | 矢印アイコン（→） |

#### 優先度ルール
1. **RETURNED（返送）** - 最優先
2. **CREATED（24時間以上経過）** - 処理遅延
3. **READY（古い順）** - 出荷待ち

#### 表示件数
- デフォルト: 5件
- 最大: 10件

## 4. 画面項目とイベント

### 4.1 初期表示時

#### イベント: ページロード
**処理内容:**
1. サマリーデータ取得
2. 優先対応リスト取得

**API呼び出し:**

```typescript
// 1. サマリー取得
GET /api/v1/shipments/summary

Response:
{
  "success": true,
  "data": {
    "created": 12,
    "ready": 5,
    "shipped_today": 8,
    "returned": 1
  }
}

// 2. 優先対応リスト取得
GET /api/v1/shipments/priority?limit=5

Response:
{
  "success": true,
  "data": [
    {
      "id": 1,
      "order_id": "ORD-001",
      "status": "RETURNED",
      "carrier": "YAMATO",
      "tracking_number": "123456789012",
      "shipping_address": "東京都...",
      "created_at": "2026-01-01T00:00:00Z",
      "updated_at": "2026-01-02T00:00:00Z"
    }
  ]
}
```

**エラーハンドリング:**
- API エラー時: エラートースト表示
- データなし時: "現在、優先対応が必要な発送はありません" メッセージ表示

---

### 4.2 サマリーカードクリック

#### イベント: カードクリック
**処理内容:**
発送一覧画面（SCR-002）へ遷移し、該当ステータスでフィルタ

**遷移先URL:**
- 未着手カード: `/shipping/list?status=CREATED`
- 出荷作業待ちカード: `/shipping/list?status=READY`
- 本日出荷カード: `/shipping/list?status=SHIPPED&date=today`
- 返送/トラブルカード: `/shipping/list?status=RETURNED`

**API呼び出し:**
なし（クライアントサイド遷移のみ）

---

### 4.3 優先対応リスト行クリック

#### イベント: 行クリック / 矢印アイコンクリック
**処理内容:**
発送詳細画面（Sheet/Drawer）を開く

**API呼び出し:**

```typescript
GET /api/v1/shipments/:order_id

Response:
{
  "success": true,
  "data": {
    "id": 1,
    "order_id": "ORD-001",
    "status": "RETURNED",
    "carrier": "YAMATO",
    "tracking_number": "123456789012",
    "shipping_address": "東京都渋谷区...",
    "ready_at": "2026-01-01T10:00:00Z",
    "shipped_at": "2026-01-02T09:00:00Z",
    "delivered_at": null,
    "version": 3,
    "created_at": "2026-01-01T00:00:00Z",
    "updated_at": "2026-01-02T09:00:00Z"
  }
}
```

**UI動作:**
- 右側から Sheet/Drawer がスライドイン
- 詳細情報と編集フォームを表示（SCR-003参照）

---

### 4.4 「すべての発送を見る」ボタンクリック

#### イベント: ボタンクリック
**処理内容:**
発送一覧画面（SCR-002）へ遷移

**遷移先URL:**
`/shipping/list`

**API呼び出し:**
なし（クライアントサイド遷移のみ）

---

### 4.5 自動更新（オプション）

#### イベント: 定期ポーリング（30秒〜60秒間隔）
**処理内容:**
サマリーと優先対応リストを自動更新

**API呼び出し:**
- GET /api/v1/shipments/summary
- GET /api/v1/shipments/priority?limit=5

**実装方針:**
- MVP では手動リロードのみ
- 将来的に WebSocket / SSE で実装可能

## 5. バリデーション

本画面には入力項目がないため、バリデーションは不要。

## 6. エラーハンドリング

| エラー種別 | HTTP Status | UI動作 |
|-----------|-------------|--------|
| API接続エラー | - | エラートースト表示 + リトライボタン |
| サーバーエラー | 500 | "システムエラーが発生しました" トースト表示 |
| データなし | 200（空配列） | "優先対応が必要な発送はありません" メッセージ |

## 7. 非機能要件

### 7.1 パフォーマンス
- 初期表示: 1秒以内
- API レスポンス: 500ms 以内

### 7.2 アクセシビリティ
- カードはキーボード操作可能（Tab + Enter）
- スクリーンリーダー対応（aria-label 設定）

### 7.3 レスポンシブ対応
- モバイル: カードを縦1列に配置
- タブレット: カードを2列に配置
- デスクトップ: カードを4列に配置

## 8. 実装メモ

### 8.1 使用コンポーネント（shadcn/ui）
- Card: サマリーカード
- Badge: ステータス表示
- Table: 優先対応リスト
- Button: アクションボタン
- Toast: エラー通知

### 8.2 状態管理
```typescript
interface DashboardState {
  summary: {
    created: number;
    ready: number;
    shipped_today: number;
    returned: number;
  } | null;
  priorityShippings: Shipping[];
  isLoading: boolean;
  error: string | null;
}
```

### 8.3 API Client 実装例
```typescript
// lib/api/shipping-client.ts
export const shippingApi = {
  getSummary: () => 
    fetch(`${API_BASE_URL}/api/v1/shipments/summary`),
  
  getPriority: (limit = 5) => 
    fetch(`${API_BASE_URL}/api/v1/shipments/priority?limit=${limit}`),
};
```
